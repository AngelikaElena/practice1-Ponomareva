# Задание 3. Комплексный ремонт скважин (Практика 2)

**ФИО:** Пономарева Анжелика Алексеевна

## 📋 Постановка задачи
Поступает заявка на ремонт, состоящая из нескольких работ (бурение, электрика, логистика).
Нужно получить расчеты от трех разных служб и собрать их в единую смету.

## 🧩 Использованные паттерны интеграции

1. **Составной обработчик сообщений (Composed Message Processor)** — общий паттерн, объединяющий:
   * **Разделитель (Splitter)** — разбивает общую заявку на отдельные работы.
   * **Маршрутизатор (Message Router)** — направляет работы в нужные очереди (`q_drilling`, `q_electrical`, `q_logistics`).
   * **Агрегатор (Aggregator)** — собирает три ответа в одну смету.
2. **Идентификатор корреляции (Correlation Identifier)** — используется `request_id`, чтобы Агрегатор понял, что три пришедших расчета относятся к одной и той же заявке.
3. **Запрос-ответ (Request-Reply)** — Инициатор отправляет заявку и ждет ответа в очереди `final_estimates`.
4. **Гарантированная доставка (Guaranteed Delivery)** — `durable=True` и `delivery_mode=2` для надежности.
